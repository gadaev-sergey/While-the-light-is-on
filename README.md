# Убежище · база исследования

**While the light is on** · [Играть в браузере](https://gadaev-sergey.github.io/While-the-light-is-on/) · [Репозиторий](https://github.com/gadaev-sergey/While-the-light-is-on)

**[GDD — источник истины о замысле, лоре и устройстве уровней](GDD.md).** README описывает текущую реализацию и её запуск.

Новый 2.5D прототип дома в разрезе, ориентированный на пространственные принципы This War of Mine. Два жилых этажа, подвал, шесть помещений, лестницы и дворовая территория. Из предыдущей игры сохранён разработчик с пузиком, очками, худи и клавиатурой. Прежний лор о багах, офисные уровни и система суперкомбинаций не используются. Актуальная история происходит в 2034 году после Третьей мировой войны; её вступление с выходом из бункера и поиском убежища пока не реализовано.

## Запуск

Node.js 22.14+ и npm:

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/. Игра сразу начинается на базе. Production: `npm run build`, затем `npm run preview`. Результат в `dist/` работает на статическом хостинге; сервер, аккаунт и API-ключи во время игры не нужны.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при каждом push в `main` или вручную из GitHub Actions: устанавливает зависимости через `npm ci`, проверяет механику, собирает игру и публикует только `dist/`. В Settings → Pages источник публикации — **GitHub Actions**. Секреты вручную добавлять не нужно: используются стандартные права `GITHUB_TOKEN`.

`npm run build:pages` включает префикс `/While-the-light-is-on/` для HTML, CSS и всех игровых изображений. Обычная локальная разработка продолжает работать по корневому адресу.

Для проверки этой сборки запустите `npm run preview -- --mode pages`, а в другом терминале — `npm run test:deployment`. Проверка использует Google Chrome и проверяет загрузку всех 11 PNG, отсутствие ошибок, взаимодействия, фонарик, план и мобильный экран. Опубликованный сайт можно проверить командой:

```sh
npm run test:deployment -- https://gadaev-sergey.github.io/While-the-light-is-on/
```

## Текущая локация

Дом собирается из шаблонов сооружения, комнат, проёмов и лестниц. Два надземных этажа и подвал, всего шесть помещений. У каждой комнаты своя перспектива к её центру: видны обе боковые стены, пол и потолок сходятся с ними без зазоров. Окна, откосы и ступени согласованы с этой проекцией; чёрные срезы имеют неровные стыкующиеся края. Двери плавно поворачиваются на петлях у дальней стены, их проёмы свободны от чёрной заливки. Полотна закрывают мебель, но остаются за персонажем и низким передним декором. Жилые этажи соединяет марш с двумя рядами перил, подвал — вертикальная лестница. В комнаты возвращены семь предметов с новыми фронтальными спрайтами. Радиаторы, пятна дымки и небольшой передний декор добавляют глубину. Во дворе остаются бочка, новый ящик и один пёс.

Шесть окон выбиты. Два пролома в задней стене открывают вид на реальный задний фон; через третий, в перегородке верхнего этажа, можно пройти между комнатами. Ремонт досками подготовлен как отдельное сохраняемое состояние каждого проёма. Игровое действие ремонта, его стоимость и длительность пока не введены.

**[Таблица слоёв и объектов](docs/base/LAYERS.md)** содержит назначения всех текущих предметов и шаблон новых записей. Задний фон, стены и световая дымка находятся позади дверей, мебели, полов, лестниц и героя. Непрозрачные поверхности освещаются отдельно; лучи не просвечивают сквозь них. После сборки применяется слабое размытие вне обзора с мягким краем. Напольное покрытие размывается вне обзора. Поверх остаются чёткими вертикальные перегородки; срезы здания и грунта рисуются чёрным, затем рисуются маркеры. Шаблоны сооружений описаны в [документации модулей](docs/base/MODULES.md).

## Основные механики

- **Исследование.** A/D перемещают героя; W/S включают лестничный переход. Щелчок по помещению строит маршрут через лестницы. Закрытые двери блокируют движение и обзор.
- **Двери.** При подходе к закрытой двери герой останавливается и берётся за ручку. Открытая дверь закрывается одним нажатием E, без позы у ручки и панели выбора. E открывает дверь, Q наклоняет героя к скважине и даёт узкий обзор, Esc или шаг назад прекращают взаимодействие. Есть поддержка сюжетных замков; в текущем доме двери не заперты. Взгляд через скважину не пропускает фонарик за полотно.
- **Туман и фонарик.** Вне геометрического обзора сцена размывается, важные предметы и пёс скрыты. Фонарик лишь добавляет свет: он не расширяет обзор и не создаёт свечения вокруг героя. Сплошные перекрытия и закрытые двери отсекают и обзор, и свет. Лестничные проёмы пропускают оба между этажами, сохраняя переднюю кромку пола.
- **Время суток.** Часы сверху позволяют выбрать утро, день, вечер, ночь или точное время. Есть автоматическая смена. Без питания комнаты темны, как подвал. Дневной свет проходит через всю сквозную форму окон и проломов, учитывая рамы и края кладки; мягко затухает, проходит через открытые двери и лестничные проёмы. Чёрные срезы сохраняют цвет при любом освещении. Ручной выбор останавливает часы.
- **Ночное небо.** Луна с мягким ореолом и редкие звёзды появляются в сумерках. Через открытые проёмы входит слабый холодный свет; закрытые комнаты остаются тёмными. Небесные тела находятся на заднем плане. Туман размывает задний свет и материалы ближних объектов отдельно, сохраняя непрозрачные силуэты мебели и лестниц.
- **Повреждения.** Проломы на заднем плане и в плоскости движения различаются в данных. Вид через заднюю стену не даёт возможности пройти сквозь соседние перекрытия.
- **Припасы во дворе.** Ящик обыскивается один раз, из бочки можно набрать воду дважды. Действия прерываются движением и выдаются только по завершении таймера.
- **Сохранения.** Версия 3 хранит состояние дверей и повреждений, найденные вещи, исследованные комнаты, героя и режим часов. Ключ `shelter-base-v1` оставлен для миграции прежних сохранений: удалённые предметы и свет от старого генератора не восстанавливаются.
- **Предметы дома.** Можно обыскать ящики и шкаф, набрать воду, отдохнуть, сделать бинт на верстаке и запустить генератор в подвале за 2 детали и предохранитель. Эти действия используют прежние тестовые правила; окончательный баланс ещё не утверждён.

## Архитектура

```text
src/base/config.ts       Сборка текущей локации и предметы двора
src/base/level.ts        Шаблоны, экземпляры, проёмы и проверка геометрии
src/base/architecture.ts Перспектива каждой комнаты, поворот двери и неровные края
src/base/types.ts        Контракты состояния и сохранения
src/base/world.ts        Движение, взаимодействия, AI и прогресс
src/base/visibility.ts   Отсечение лучей стенами, обзор, память комнат
src/base/lighting.ts     Суточный свет, источники в проёмах и часы
src/base/night-sky.ts    Луна, звёзды и контур открытого неба
src/base/aperture-light.ts Свет от сквозной формы отверстия, отсечение препятствиями
src/base/layers.ts       Реестр слоёв и поверхностей для их сборки
src/base/renderer.ts     2.5D слои, геометрия дома, туман, свет и маркеры
src/base/hero.ts          Сохранённые спрайты разработчика и плавные позы
src/base/animation.ts     Временные клипы и смешивание
src/base/input.ts         Клавиатура, мышь, сенсорные действия
src/base/ui.ts            Новый интерфейс базы, рюкзак, план и справка
src/base/assets.ts        Загрузка PNG, атласов и масок архитектурных проёмов
src/main.ts              Шаг 60 Hz, интерполяция и автосохранение
public/assets/base/      Окружение, атлас повреждений и один противник
archive/beat-em-up/       Прежний офисный прототип и неиспользуемые ассеты
```

2.5D здесь реализовано как боковая игровая плоскость с объёмными торцами стен, глубиной пола, многослойным фоном, перспективой мебели и динамическим светом. Рендер — Canvas 2D, навигация — по этажам и лестницам, свободного перемещения в трёхмерной сцене нет. Симуляция не зависит от DOM. В dev-сборке доступна только копия состояния `window.__BASE__.snapshot()`; API отсутствует в production.

## Проверки и дальнейшая работа

```sh
npm test
npm run build
npm run test:e2e
```

Тесты проверяют сборку нескольких домов, изменение этажности, геометрию проёмов, движение и свет, миграцию сохранений, порядок слоёв по пикселям и живой ввод в Chrome. Браузерные тесты используют установленный Google Chrome. `node scripts/inspect.mjs` сохраняет снимки сцены в `artifacts/base/`.
