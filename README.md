# Убежище · база исследования

**While the light is on** · [Играть в браузере](https://gadaev-sergey.github.io/While-the-light-is-on/) · [Репозиторий](https://github.com/gadaev-sergey/While-the-light-is-on)

Новый 2.5D прототип дома в разрезе, ориентированный на пространственные принципы This War of Mine. Два жилых этажа, подвал, шесть помещений, лестницы и дворовая территория. Из предыдущей игры сохранён разработчик с пузиком, очками, худи и клавиатурой. Лор, офисные уровни и система суперкомбинаций не используются.

## Запуск

Node.js 22.14+ и npm:

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/. Игра сразу начинается на базе. Production: `npm run build`, затем `npm run preview`. Результат в `dist/` работает на статическом хостинге; сервер, аккаунт и API-ключи во время игры не нужны.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при каждом push в `main` или вручную из GitHub Actions: устанавливает зависимости через `npm ci`, проверяет механику, собирает игру и публикует только `dist/`. В Settings → Pages источник публикации — **GitHub Actions**. Секреты вручную добавлять не нужно: используются стандартные права `GITHUB_TOKEN`.

`npm run build:pages` включает префикс `/While-the-light-is-on/` для HTML, CSS и всех игровых изображений. Обычная локальная разработка продолжает работать по корневому адресу.

Для проверки этой сборки запустите `npm run preview -- --mode pages`, а в другом терминале — `npm run test:deployment`. Проверка использует Google Chrome и проверяет загрузку всех восьми PNG, отсутствие ошибок, взаимодействия, фонарик, план и мобильный экран. Опубликованный сайт можно проверить командой:

```sh
npm run test:deployment -- https://gadaev-sergey.github.io/While-the-light-is-on/
```

На сенсорном экране есть стрелки, лестничные кнопки, действие E и фонарик. Физические коды клавиш работают с русской раскладкой. При потере фокуса игра останавливается.

## Основные механики

- **Вертикальность.** Между этажами можно пройти только по лестнице. Герой сначала подходит к ступеням, затем плавно поднимается или спускается. Щелчок по другому этажу строит маршрут через лестничные связи. Закрытые двери блокируют проход.
- **Туман войны.** Неизученные комнаты скрыты почти полностью. План и слабый силуэт помещения остаются после исследования, но интерактивные предметы, их значки и противник рисуются только в текущем поле зрения. Память комнаты не открывает её содержимое на расстоянии.
- **Фонарик.** Направленный луч расширяет обзор до 455 мировых пикселей. Закрытые двери, стены и перекрытия обрезают его. В лестничных проёмах есть реальные зазоры. Рядом с героем остаётся небольшой обзор даже с выключенным фонариком. Физическая проверка видимости и маска освещения используют одинаковую геометрию.
- **Взаимодействия.** Двери открываются и закрываются; ящики, шкаф и аптечку можно обыскать; завалы разбираются; вода собирается из бочки и мойки. Действия имеют продолжительность, движение или повторное E отменяет их. Ресурсы выдаются только в конце, повторный обыск не создаёт новые вещи.
- **База.** Из двух единиц ткани верстак делает бинт, кровать восстанавливает здоровье. Генератор требует две детали и предохранитель; после запуска включаются лампы и расширяется ближний обзор. Это небольшой цикл для проверки механик, без сюжетных задач и обязательной победы.
- **Один противник.** Пёс находится у дальнего правого забора, ходит в ограниченном участке и не преследует героя в доме. Перед укусом предупреждает, от направленного света отступает. Его можно оттолкнуть J.
- **Прогресс.** Двери, найденные вещи, ресурсы, исследованные помещения, здоровье, питание дома и состояние фонарика сохраняются автоматически в localStorage (`shelter-base-v1`). Незавершённое действие и движение по лестнице не сериализуются; при закрытии во время них используется последнее сохранение. Пауза → «Начать заново» очищает текущий забег.

## Архитектура

```text
src/base/config.ts       Дом, комнаты, лестницы, двери, предметы
src/base/types.ts        Контракты состояния и сохранения
src/base/world.ts        Движение, взаимодействия, AI и прогресс
src/base/visibility.ts   Отсечение лучей стенами, обзор, память комнат
src/base/renderer.ts     2.5D слои, геометрия дома, туман, свет и маркеры
src/base/hero.ts          Сохранённые спрайты разработчика и плавные позы
src/base/animation.ts     Временные клипы и смешивание
src/base/input.ts         Клавиатура, мышь, сенсорные действия
src/base/ui.ts            Новый интерфейс базы, рюкзак, план и справка
src/base/assets.ts        Загрузка только активных PNG
src/main.ts              Шаг 60 Hz, интерполяция и автосохранение
public/assets/base/      Новое окружение и один противник
archive/beat-em-up/       Прежний офисный прототип и неиспользуемые ассеты
```

2.5D здесь реализовано как боковая игровая плоскость с объёмными торцами стен, глубиной пола, многослойным фоном, перспективой мебели и динамическим светом. Рендер — Canvas 2D, навигация — по этажам и лестницам, свободного перемещения в трёхмерной сцене нет. Симуляция не зависит от DOM. В dev-сборке доступна только копия состояния `window.__BASE__.snapshot()`; API отсутствует в production.

## Проверки и дальнейшая работа

```sh
npm test
npm run build
npm run test:e2e
```

Тесты проверяют стены и свет, скрытые предметы, лестницы, отмену и завершение действий, ресурсы, единственного врага, сохранения и живой ввод в Chrome. Браузерные тесты используют установленный Google Chrome. `node scripts/inspect.mjs` сохраняет снимки сцены в `artifacts/base/`.
