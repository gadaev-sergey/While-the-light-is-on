# Shelter Engine

Для создания игр и играбельных прототипов, добавления функций и исправления игровых ошибок используй [skills/shelter-game-release/SKILL.md](skills/shelter-game-release/SKILL.md). Это правило владельца: готовый результат нужно публиковать на GitHub Pages и добавлять или обновлять в каталоге Shelter Arcade. Явный запрет публикации в текущем запросе имеет приоритет.

Проекты находятся в `games/`, контракты движка — в `docs/engine/SDK.md`. Каталог хранится в `catalog/`, его реестр — `catalog/games.json`. Существующие незакоммиченные изменения не затирать и не включать целиком в публикацию; штатные команды выпуска отправляют только готовые файлы.

В начале каждого хода разработки конкретной игры привязывай учёт командой `npm run usage:begin -- games/<id>`, в конце синхронизируй `npm run usage:sync -- games/<id>`. Учитывай реальные токены и модели из журналов Codex; не относить общую работу над движком и каталогом к одной из игр. Подробности — в указанном навыке.
