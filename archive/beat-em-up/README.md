# NULLPOINT

Игровой 2D beat ’em up прототип: разработчик сражается с ожившими багами и фичами в офисе после пятничного релиза. Три уровня — вестибюль, отдел разработки и серверный центр — содержат по два этажа с лестницей. Между уровнями перевозят лифты; в забеге десять противников, два выбора усилений и босс «Регрессия».

## Запуск

Требуется Node.js 22.14+ и npm.

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Для production:

```sh
npm run build
npm run preview
```

Каталог `dist/` можно разместить на обычном статическом хостинге. Серверная часть, API-ключи и сетевые сервисы во время игры не нужны. Ассеты включены в проект. Для размещения в подкаталоге задайте `base` в конфигурации Vite и пересоберите проект.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение по коридору и лестнице | WASD / стрелки |
| Удар левой рукой | J / левая кнопка мыши |
| Тяжёлый удар клавиатурой | K / правая кнопка мыши |
| Удар ногой | L |
| Заряженный суперудар | R |
| Блок / парирование | Удерживать Q |
| Прыжок | Пробел |
| Рывок с краткой неуязвимостью | Shift |
| Отладочный импульс по области | E |
| Лифт после зачистки, справа на верхнем этаже | F |
| Пауза | Escape |

Физические коды клавиш работают и с русской раскладкой. На сенсорном экране доступны стрелки и кнопки способностей. При потере фокуса игра автоматически останавливается.

Перед ударом врага появляется оранжевая область. Рывок позволяет избежать урона, а прыжок — перепрыгнуть наземную атаку. В воздухе доступны движение, все три базовые атаки и рывок. Повторный прыжок доступен после приземления. Для ближней атаки нужно находиться на одной полосе и высоте с целью и смотреть в её сторону. Импульс действует вокруг героя. Фрагменты и аптечки притягиваются с небольшого расстояния; оставшиеся предметы автоматически собираются при очистке зоны.

## Комбинации

Нажимайте следующую кнопку **после полного завершения текущего удара**. Ранние нажатия, в том числе во время остановки кадра при попадании, отбрасываются. Удержание кнопки не повторяет удар, одновременное нажатие J/K/L запускает только один приём. Полоса в HUD показывает восстановление. После его окончания есть 0,9 секунды на продолжение связки.

Только успешные завершённые попадания на земле складываются в рецепт. Третий удар остаётся обычной атакой и заряжает **отдельный суперудар на R**. Заряд хранится 14 секунд игрового времени. Суперудар можно выпустить на земле после окончания атаки; он имеет собственный замах, эффект и урон.

| Связка, затем R | Суперудар | Результат | Базовый урон связки + супер |
| --- | --- | --- | --- |
| J → J → K → R | CTRL · ALT · DEL | Расширяющаяся ударная волна, сбивание толпы | 78 + 115 |
| J → L → K → R | STACK OVERFLOW | Столбы кода подбрасывают противников | 86 + 96 |
| K → J → L → R | HOTFIX | Большая электрическая клавиша пронзает врагов на дистанции | 86 + 130 |

После STACK OVERFLOW дождитесь конца приёма, прыгните следом и ударьте в воздухе. Высота врагов физическая: наземный удар не попадает по слишком высокой цели. Воздушные попадания постепенно теряют урон. Босс не подбрасывается; все три суперудара пробивают его броню во время замаха. Один эффект суперудара поражает каждую цель только один раз.

Промах, разворот между ударами, полученный урон и рывок сбрасывают незавершённую связку. Рывок и импульс не прерывают текущую атаку. Q защищает спереди: первые 0,15 с парируют без урона, поздний блок пропускает 20% урона. Запас защиты восстанавливается при отпущенном блоке.

**«Тренировка комбинаций»** запускает безопасную мишень с автоматическим восстановлением. **«Приёмы»** открывают справочник. HUD показывает принятые нажатия, доступные продолжения, готовность к следующему удару, заряд R и суммарный урон. Все действия доступны также экранными кнопками.

## Офис, этажи и лифты

Каждый уровень содержит два полноценных этажа, разделённых 280 игровыми пикселями. Нижний коридор проходит под верхним: одинаковые x/y могут относиться к разным этажам. Для подъёма подойдите к первой ступени в глубине коридора (W), затем идите вправо (D). Спуск проходит по той же лестнице влево. Прыжок не переносит сквозь перекрытие. У проёма сверху стоят перила, блокирующие случайный шаг в середину лестницы. Противники самостоятельно заходят к её основанию или верхней площадке.

После зачистки обоих этажей лифт справа наверху открывается. Подойдите к двери и нажмите **F** или экранную кнопку лифта. Во время поездки двери закрываются и появляется название следующего отдела. Между уровнями доступен выбор усиления, затем герой выходит на нижнем этаже нового офиса. Последний лифт завершает забег. Пауза останавливает поездку, повторные нажатия её не дублируют.

Фон — рисованные рабочие места, окна с вечерним городом и переговорные. Передний план содержит только отдельные небольшие офисные предметы: коробки, бухту кабеля, растение, корзину с бумагой, кейс и папки. Высота исходных прямоугольников на экране не превышает 56 пикселей; предметы стоят у передней кромки пола, лица и атаки остаются видны. Нижний пол, верхнее перекрытие и лестница используют общую текстуру ковровой плитки и металлических перекрытий. Периодическая текстура сохраняет положение при прокрутке.

## Что есть в прототипе

- Оригинальная рисованная панорама, отдельная текстура пола, разработчик в очках и худи с пузиком, циклы ходьбы, клавиатуры, прыжка и кулака по 8 кадров, 9 поз пинка, 6 кадров врагов и 6 низких офисных объектов и отдельный лифт. Окружение и монстры перерисованы с тем же чернильным контуром и живописной фактурой, что и герой.
- Три офисных уровня с шестью этажами, лестницами, лифтами, параллаксом, бликами и частицами.
- Три базовых удара, три отдельных суперудара, воздушные серии, блок и парирование, отбрасывание, краткая остановка кадра при попадании, разлетающиеся клавиши, прыжок, рывок, импульс и всплывающий урон.
- Три вида противников с разным поведением. У босса удар по заранее отмеченной области.
- Улучшения урона, перезарядки и восстановления здоровья между зонами.
- Тренировочный режим, справочник приёмов, главное меню, HUD, пауза, результаты, перезапуск, карта, бестиарий, история мира и просмотр полных ассетов.
- Синтезированные звуковые эффекты через Web Audio. Настройки громкости, частиц, тряски и сложности сохраняются локально. Лучший завершённый забег записывается в localStorage; сохранения незаконченного забега пока нет.

## Структура

```text
public/assets/          Полные исходные PNG
src/game/content.ts     Враги, зоны, улучшения и размещение декораций
src/game/combat.ts      Приёмы, рецепты комбинаций, тайминги и анимации ударов
src/game/sprites.ts     Измеренные прямоугольники кадров и точки опоры
src/game/animation.ts   Локальные циклы, плавное смешивание поз и интерполяция
src/game/locomotion.ts  Скорость, фаза шагов по расстоянию и параметры прыжка
src/game/pose-painter.ts Нормализация кадров вокруг общей точки опоры
src/game/terrain.ts     Этажи, лестницы, поиск опоры и маршруты для AI
src/game/ground.ts      Подготовка и прокрутка бесшовной текстуры пола
src/game/world.ts       Симуляция, бой, AI, предметы, переходы состояний
src/game/renderer.ts    Canvas 2D, камера, слои, спрайты, эффекты
src/game/office-renderer.ts Офисные перекрытия, лестницы, лифт, передний план
src/game/input.ts       Клавиатура, мышь и отсечение раннего ввода
src/game/audio.ts       Синтез звуков
src/game/assets.ts      Загрузка ресурсов с отображением прогресса
src/ui/interface.ts    DOM-интерфейс, модальные окна, HUD
src/main.ts             Фиксированный шаг симуляции 60 Hz и цикл отрисовки
docs/                   Описание ассетов и рекомендации по расширению
tests/                  Тесты симуляции и браузерные сценарии
```

Симуляция не зависит от DOM, рендера или звукового движка. UI и звук подключены через события. Частицы ограничены по количеству; pixel ratio ограничен двумя. Production-код не содержит диагностического API. В dev-сборке `window.__NULLPOINT__.snapshot()` предоставляет копию состояния для проверок, без возможности изменять игру.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют установленный Google Chrome и автоматически запускают Vite, если он ещё не запущен. Они проверяют управление, паузу, меню, настройки, полный забег без изменения игрового состояния и мобильные кнопки. Для среды без Chrome установите Chromium командой `npx playwright install chromium` и уберите `channel: 'chrome'` из `playwright.config.ts`.

`node scripts/inspect.mjs` сохраняет визуальные снимки меню, боя, архива и мобильного экрана в `test-results/`; предварительно запустите dev-сервер.

## Следующий этап

Анимации используют собственные атласы, плавное смешивание и опорные точки. Ходьба привязана к пройденному расстоянию, высота отделена от глубины дорожки, рендер интерполирует физику. Пол строится один раз как периодическая текстура. Следующие шаги: больше клипов противникам, новые рецепты суперударов, интерактивные предметы, музыка и другие локации. Контракты расширения описаны в `docs/EXTENDING.md`.

Все растровые ассеты созданы встроенным `image_gen.imagegen`. Исходники любимого героя сохранены. Промпты офиса и удара левой рукой находятся в `docs/office-asset-prompts.json`, предыдущих монстров и пинка — в `docs/combat-world-asset-prompts.json`, исходные промпты разработчика — в `docs/developer-asset-prompts.json`. Фактические размеры и раскладки атласов перечислены в `docs/ASSETS.md`.
