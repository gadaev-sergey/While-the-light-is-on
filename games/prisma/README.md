# Призма · Сад света

Законченная оптическая головоломка на Shelter Engine SDK 1. Двенадцать сцен в трёх главах: отражение, разделители и два цвета. Цель — одновременно зажечь все приёмники лучами соответствующих цветов.

Нажмите на зеркало или разделитель для поворота на 90°. Разделитель сохраняет прямой луч и добавляет отражение. Лучи свободно пересекаются; камни и приёмники поглощают их. Круглый приёмник ждёт янтарный луч, ромбовидный — бирюзовый. Все сцены имеют проверенное решение.

Клавиши: Tab и Enter / пробел — элементы поля; Z — отмена; R — сброс композиции; H — подсказка; M — звук; Esc — выбор уровня. Есть сенсорное управление. Нет таймера, рекламы и внешних ресурсов. Визуальные эффекты учитывают `prefers-reduced-motion`.

Три звезды: оптимальное число поворотов без подсказок. Две: любое решение без подсказок. Одна: решение с подсказками. Подсказка показывает следующий поворот к ближайшему решению текущего поля. Лучшие звёзды и незавершённые композиции сохраняются локально; изолированные сеансы редактора не читают и не меняют сохранения.

Сцены находятся в `scenes/`, логика трассировки — `scripts/world.ts`, управляемый сеанс SDK — `scripts/runtime.ts`, SVG-визуализация — `scripts/renderer.ts`. Свет, элементы и звуки создаются кодом. Редактор хранит элементы как нативные узлы `prisma.optic`.

Проверка: `node --experimental-strip-types --test tests/prisma/world.test.ts` и `npx tsc --noEmit` из корня движка. Сборка: `npm run build:game -- games/prisma`. Локальная игра: `node games/prisma/launch.mjs`. Выпуск: `npm run release:game -- games/prisma`.

Жанр выбран после просмотра проектов и каталога: оптических головоломок среди существующих игр не было.
