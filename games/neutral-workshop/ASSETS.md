# Ресурсы перенесённой игры

В `assets/` скопированы без изменения все 16 файлов графики While the light is on: четыре GLB-модели и двенадцать PNG. Идентичность файлов проверена SHA-256; полный список и контрольные суммы находятся в `artifacts/engine/workshop-game-import/migration.json` от корня репозитория.

| Ресурсы | Назначение |
| --- | --- |
| `base/models/wardrobe.glb`, `crates.glb`, `sink.glb`, `bed.glb` | Шкаф, ящики, раковина и кровать. Модели построены в Blender по собственным изображениям проекта; текстуры WebP встроены в GLB. |
| `base/district.png` | Фон квартала. |
| `base/materials.png` | Шесть фактур архитектуры. |
| `base/furniture.png`, `base/interior-front.png`, `base/crates-front.png` | Атласы мебели и фронтальных ящиков. |
| `base/objects.png` | Предметы и реквизит. |
| `base/house-damage.png` | Окна, проломы и обломки. |
| `base/dog.png` | Позы пса. |
| `developer-walk.png`, `developer-attack.png`, `developer-left-punch.png`, `base/developer-door.png` | Ходьба, стойка, отталкивание и взаимодействие героя с дверями. |

PNG созданы для исходной игры с помощью генерации изображений. Спрайты и изображения сторонних игр не копировались. Отдельная публичная лицензия для графики игры не объявлена; перенос не меняет её происхождение или права. Подробная история и промпты остаются в `docs/base/ASSETS.md` исходного репозитория.

В каталоге ресурсов проекта также сохранены прежние стол, стул, текстурированный ящик, карта дерева и PBR-материал Neutral Workshop. Они основаны на оригинальном Shelter Starter Content, CC0-1.0; их метаданные сохранены в `project.shelter.json`.

Процедурная архитектура, небо, свет и звук создаются игровым кодом из `scripts/game/`; дополнительных загрузок из сети не требуется.
