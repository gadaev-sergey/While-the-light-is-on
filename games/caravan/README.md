# Караван · Пески рассвета

Законченная игра в жанре tower defense на Shelter Engine SDK 1. Три последовательные карты, 10 волн на каждой, четыре башни с тремя уровнями, четыре вида врагов и солнечный импульс. Графика — процедурный Canvas 2D; короткие звуковые сигналы — Web Audio, без внешних ресурсов.

Выберите башню, затем площадку +. Башни стреляют автоматически по врагу, ближайшему к воротам. Выберите построенную башню для улучшения или продажи за 70% вложений. Победите в 10 волнах, сохранив хотя бы одно из 20 очков ворот. Страж в последней волне снимает 8 очков при проходе; панцирник — 2; другие — 1.

Управление: мышь или касания; 1–4 — выбор башни; пробел — следующая волна; E — солнечный импульс; F — скорость 1×/2×; P — пауза; M — звук; Esc — меню. Клавиатурная навигация по площадкам: Tab / Enter. Вкладка автоматически ставит бой на паузу при скрытии.

Прогресс завершённых карт и лучшие звёзды сохраняются в localStorage под ключом проекта, кроме изолированного предпросмотра редактора. Текущий бой не сохраняется. Три звезды — 20 очков ворот; две — 12–19; одна — 1–11. Настройка уменьшения движения отключает декоративную анимацию.

Карты — нативные сцены `scenes/*.scene.json` с данными маршрута и площадок в `moduleData.caravan`. Модуль экспортирует управляемую сессию и освобождает анимацию, события и звук при завершении.

Проверка: `npx tsc --noEmit`, `node --experimental-strip-types --test tests/caravan/world.test.ts`.
Выпуск: `npm run release:game -- games/caravan`.
