# ЗАРЕВО · Ночная гонка

Аркадные гонки в псевдо-3D на Shelter Engine SDK 1. Восемь машин на старте,
таймер с контрольными точками, трафик и нитро, которое заряжается смелой ездой.

## Играть

- Публичный адрес: https://gadaev-sergey.github.io/zarevo/
- Локально: `node games/zarevo/launch.mjs` или «Играть в Зарево.command» (собирает игру при отсутствии сборки, порт 5204).
- Из редактора Shelter Engine: открыть этот проект и запустить пробную игру.

←/→ или A/D — руль; ↑/W — газ; ↓/S — тормоз; пробел или Shift — нитро; Esc/P — пауза; M — звук.
На сенсорном экране газ включён всегда: слева ◀ ▶, справа «Тормоз» и «Нитро».

## Правила

- Игрок стартует последним из восьми. Таймер идёт с первой секунды; каждая контрольная точка добавляет время. Если оно кончилось — попытка окончена.
- В повороте машину выносит наружу: подруливай внутрь, на крутых виражах сбрасывай газ. Обочина тормозит, столбы, деревья и здания останавливают.
- Удар в машину впереди сбрасывает скорость. Проезд рядом с ней «впритык» и езда в её спутном потоке заряжают нитро. Нитро поднимает предельную скорость на 24%.
- Финиш в тройке открывает следующую трассу. Лучшие время и место по каждой трассе сохраняются локально; изолированный пробный сеанс прогресс не читает и не пишет.

Трассы: «Приморское шоссе» (закат, плавные виражи), «Перевал Ветров» (ночь, серпантин и перепады высот), «Неоновый город» (плотный трафик).

## Архитектура

- `scenes/*.scene.json` — штатные сцены Shelter. Трасса состоит из объектов с компонентами `zarevo.section` (участок: въезд, длина, выезд, поворот, перепад), `zarevo.checkpoint` (сегмент и бонус времени) и `zarevo.scenery` (ряд декораций). Параметры трассы — в `moduleData.zarevo`. Генератор — `scripts/create-scenes.mjs`.
- `scripts/world.ts` — детерминируемая симуляция без DOM: сегменты дороги, физика, соперники, трафик, столкновения, таймер и прогресс.
- `scripts/renderer.ts` — Canvas 2D: проекция сегментов, туман, параллакс, процедурные спрайты машин и декораций.
- `scripts/runtime.ts` — управляемый сеанс SDK: интерфейс, ввод, пауза, сохранение и освобождение ресурсов.
- `scripts/audio.ts` — процедурный мотор, эффекты и синтвейв-петля на Web Audio.

Графика, музыка и звук создаются кодом проекта; внешние ресурсы, шрифты и CDN не используются.

## Проверить и выпустить

```sh
node --experimental-strip-types --test tests/zarevo/*.test.ts
npx tsc --noEmit
npm run build:game -- games/zarevo
npm run release:game -- games/zarevo
```
