# Тихая бухта

Законченная градостроительная игра на Shelter Engine SDK 1. Постройте островной город, обеспечьте его едой и энергией и зажгите маяк.

**[Играть](https://gadaev-sergey.github.io/tidehaven/)** · [Shelter Arcade](https://gadaev-sergey.github.io/shelter-arcade/)

Три главы, 10 типов строительства, четыре сезона, торговля, городские события, оценка на 1–3 звезды и свободное строительство после финала. Графика Canvas 2D и звук Web Audio создаются процедурно, внешние ассеты и аккаунт не нужны.

Время идёт только по кнопке «Следующий сезон». Здания работают, если стоят у дороги, соединённой сторонами с ратушей. В прогнозе показаны изменения запасов в конце текущего сезона. Счастливый город с едой и свободными домами получает до 10 новых жителей за сезон. Зимой фермы производят меньше еды. Финальная цель: 80 жителей, 75% счастья, лечебница и подключённый маяк у воды. Завершите сезон, чтобы получить награду за главу или победить.

- Мышь или палец: выбрать постройку и клетку. Перетаскивание двигает карту.
- Колесо, + / − и кнопки карты: масштаб; стрелки: перемещение.
- 1–9, 0: постройки; Esc: осмотр; Z: отменить последнее строительство; M: звук.
- Снос возвращает половину стоимости. Отмена доступна до следующего строительства, сезона, торговли или события.
- Торговля доступна через меню. При нехватке средств можно запросить помощь раз в четыре сезона.
- На узком экране панель построек прокручивается горизонтально. Название с «?» открывает описание выбранной постройки.

Сохранение автоматическое в этом браузере, после каждого действия. Режим пробного запуска редактора изолирован и не меняет обычное сохранение. Для нового города предусмотрено подтверждение. Поддерживается системное уменьшение анимации.

## Локальный запуск

В корне движка дважды нажмите «Играть в Тихую бухту.command» либо выполните:

```sh
node games/tidehaven/launch.mjs
```

Локальный адрес: http://127.0.0.1:5198/. При отсутствии сборки запуск подготовит её автоматически. После правок выполните сборку заново и перезапустите сервер.

## Проект и проверки

`project.shelter.json` и `scenes/bay.scene.json` используют родные форматы движка. Карта состоит из 324 редактируемых объектов `tidehaven.tile`. SDK-модуль объявляет схему клеток, проверяет карту и создаёт управляемый RuntimeSession. Движок отвечает за проект, сборку и пространство имён сохранений; игровая симуляция и отрисовка принадлежат этому проекту.

```sh
node --experimental-strip-types --test tests/tidehaven/world.test.ts
npx tsc --noEmit
npm run build:game -- games/tidehaven
npm run release:game -- games/tidehaven
```

Проверки охватывают дорожную сеть, производство, экономику, снос и отмену, зимний урожай, голод и восстановление, события, сохранения и полное прохождение законными действиями. Контрольный маршрут достигает финала за 9 сезонов с 88 жителями без изменения ресурсов. В браузере дополнительно проверены весь маршрут, восстановление незавершённого события и адаптивный интерфейс.
