# Neutral Workshop

Независимый пример Shelter Engine SDK 1. Сцены, модели, материалы, камера, поведение и планировка созданы через интерфейс редактора; исходники игрового модуля не требуются. Используется `shelter.basic`.

Откройте эту папку в менеджере проектов и нажмите «Играть». В главной сцене: A/D — движение, W/S — лестница, E — дверь. Кнопка «Следующая сцена» открывает пустую 3D-галерею с собственной камерой и вращающимся объектом.

Два экземпляра стола и два экземпляра импортированного ящика демонстрируют независимые материалы. Планировка содержит три комнаты на двух этажах, дверь, лестницу и окно. «Собрать игру» выпускает самостоятельный Web-каталог и ZIP.

Ресурсы примера: стол, стул, карты дерева и металла — оригинальный Shelter Starter Content, CC0-1.0. Текстурированный glTF-ящик — оригинальная тестовая геометрия с картой дерева из того же набора, CC0-1.0. Материал создан из карты стартового набора. Метаданные происхождения также находятся в реестре проекта.
