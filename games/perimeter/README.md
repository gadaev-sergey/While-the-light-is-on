# ПЕРИМЕТР · Нулевой сигнал

**[Играть в браузере](https://gadaev-sergey.github.io/perimeter/)** · [Репозиторий публикации](https://github.com/gadaev-sergey/perimeter)

Готовый одиночный шутер с видом сверху на **Shelter Engine SDK 1**. Оператор 07 входит в отключённый промышленный комплекс, чтобы уничтожить источник нулевого сигнала.

Три сектора, девять волн, три тяжёлые единицы, пять типов противников, три доступных с начала оружия и восемь типов улучшений. В каждом секторе первые две волны дают выбор модификации, третья заканчивается боссом. После первых двух секторов нужно дойти до северного шлюза; уничтожение последнего босса открывает финал со статистикой и рангом. Длительность зависит от темпа игрока: это короткая аркадная операция с возможностью повторного прохождения.

## Запуск

Дважды щёлкните **Играть в Периметр.command** в корне движка. Откроется готовая игра по адресу **http://127.0.0.1:5192/**. Оставьте окно запуска открытым. Если игра уже запущена, повторный запуск просто откроет её.

Из терминала, в корне движка:

```sh
npm run play:perimeter
```

Для первого старта нужны Node.js 22.14+ и уже установленные зависимости движка. Лаунчер использует последнюю готовую Web-сборку; если сборки ещё нет, выпускает её автоматически. После изменения исходников перед запуском выполните `npm run build:game -- games/perimeter`.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD / стрелки |
| Прицел | Мышь |
| Стрелять | Удерживать ЛКМ |
| Винтовка «Вектор» | 1 |
| Дробовик «Разлом» | 2 |
| Рельсовый карабин «Игла» | 3 |
| Перезарядка | R; автоматически при пустом магазине |
| Рывок с неуязвимостью | Shift / ПКМ |
| ЭМИ: урон вокруг, уничтожение вражеских пуль | Пробел |
| Перейти через открытый шлюз | E рядом со шлюзом |
| Пауза | Esc / P |
| Звук | M |

Клавиши работают с русской раскладкой. Стрелять можно непрерывно; общий боезапас не ограничен, но магазины требуют перезарядки. Рельсовый карабин пробивает несколько машин, дробовик эффективен вблизи. Укрытия блокируют перемещение и пули. Враги показывают направление выстрела или область удара заранее.

Щит восстанавливается после четырёх секунд без урона. За каждые пять уничтоженных машин появляется аптечка; за каждые три — заряд щита. После волны щит восстанавливается целиком и добавляется 15 здоровья. Рывок проходит сквозь пули, но не сквозь укрытия. ЭМИ восстанавливается автоматически.

Три сложности: **Разведка** снижает входящий урон на 40%, **Штурм** — стандартные правила, **Ветеран** увеличивает урон на 30% и прочность противников на 12%.

На сенсорном экране есть два стика: левый для перемещения, правый для прицела и огня, а также кнопки способностей. Для мыши удобнее широкий экран. При потере фокуса игра останавливается. Интерфейс и эффекты учитывают системную настройку уменьшения движения.

## Прогресс

Автоматически сохраняется **начало каждого сектора**: ранее выбранные улучшения, сложность и статистика. После поражения кнопка «Повторить сектор» возвращает к этому состоянию. «Продолжить» в главном меню загружает тот же сектор. Незаконченная волна и улучшения, выбранные внутри текущего сектора, при повторе сбрасываются. Новая операция запрашивает подтверждение, если есть незавершённое сохранение.

Сохранение хранится локально в браузере, отдельно от других игр Shelter Engine. В пробном сеансе редактора прогресс изолирован. Перенос между разными адресами / браузерами автоматически не выполняется.

## Интеграция с движком

Откройте папку `games/perimeter` как проект в менеджере Shelter Engine и нажмите «Играть». Укрытия, точки входа, порты противников, шлюзы и разметка представлены родными объектами `shelter-scene` и компонентами `perimeter.*` со схемами для инспектора. Масштаб данных — 64 игровых пикселя на метр.

- `project.shelter.json` — манифест SDK 1 и декларация игрового модуля.
- `scenes/` — три независимые сцены в формате движка.
- `scripts/runtime.ts` — управляемый `RuntimeSession`, ввод, интерфейс, сохранение и освобождение ресурсов.
- `scripts/world.ts` — симуляция без DOM: фиксированный шаг, столкновения, оружие, AI, навигация, волны и прогресс.
- `scripts/renderer.ts` — проектная Canvas 2D отрисовка: индустриальные арены, машины, персонаж, освещение и эффекты.
- `scripts/audio.ts` — процедурные эффекты и музыкальная секвенция Web Audio.
- `scripts/create-scenes.mjs` — воспроизводимый исходник расположения объектов; повторный запуск заменяет сцены.

Движок предоставляет формат проекта, загрузку, схемы компонентов, проверку сцен и TypeScript-контрактов, запуск в редакторе, пространства имён сохранений и выпуск отдельной Web-игры. Игровые правила и отрисовка находятся в проектном модуле. Внешних изображений, шрифтов, звуков, сетевых сервисов или платных API нет.

## Сборка и проверка

```sh
npm run test:perimeter
npm run build
npm run build:game -- games/perimeter
```

Сборщик создаёт самостоятельную папку и ZIP в `artifacts/builds/perimeter-zero-signal/`. Папку можно отдавать обычным статическим HTTP-сервером. Редактор и его локальное API для выпущенной игры не нужны. Прямое открытие `index.html` через `file://` не поддерживается ES-модулями.

15 автоматических проверок охватывают сцены, движение, укрытия, попадания, оружие и перезарядку, щит, ЭМИ, паузу, улучшения, восстановление прогресса и финал. Один тест проходит **всю кампанию обычными управляющими командами**, без телепортации, удаления врагов или изменения здоровья: 55 уничтоженных машин, шесть выбранных улучшений, два пройденных шлюза и итоговая победа на стандартной сложности.

Отладочное состояние `window.__PERIMETER__` существует только в dev-сеансе и исключается из выпускаемой игры.
