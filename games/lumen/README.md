# Люмен · Последний маяк

**[Играть в браузере](https://gadaev-sergey.github.io/lumen/)** · [Репозиторий публикации](https://github.com/gadaev-sergey/lumen)

Законченный атмосферный 2D-платформер на Shelter Engine SDK 1. Три района ночного города, девять линз и три маяка. Соберите линзы, зажгите маяки и верните городу рассвет. Искры на верхних маршрутах — дополнительная цель. После последнего маяка появится финал с временем, количеством искр и возвращений.

## Играть

Дважды щёлкните **Играть в Люмен.command** в корне движка. Игра откроется в браузере по адресу http://127.0.0.1:5190/. Оставьте окно запуска открытым. Для следующего запуска есть та же команда; терминал и редактор настраивать не нужно.

Для запуска из редактора откройте эту папку как проект и нажмите **Играть**. Три сцены находятся в родном формате `shelter-scene`; платформы, предметы, враги и контрольные точки представлены объектами со схемами компонентов `lumen.*`. Тестовый сеанс редактора изолирован от обычного прогресса.

| Действие | Клавиши |
| --- | --- |
| Идти | A / D или ← / → |
| Прыгнуть, затем прыгнуть ещё раз в воздухе | Пробел, W или ↑ |
| Рывок; пробить тень | Shift или K |
| Зажечь маяк | E или ↓ |
| Пауза | Esc или P |
| Звук | M |

Клавиши работают с русской раскладкой. На сенсорном экране появляются кнопки управления. Длинное нажатие делает прыжок выше. Линзы восстанавливают одно деление здоровья, огоньки — все три. На тень также можно прыгнуть сверху. Падение возвращает к последнему огоньку, собранные предметы сохраняются. Прогресс автоматически записывается в браузере; **Продолжить путь** возвращает к огоньку. При потере фокуса игра ставится на паузу.

## Устройство

- `project.shelter.json` — проект Shelter Engine с тремя сценами и модулем SDK 1.
- `scenes/*.scene.json` — авторская геометрия и размещение игровых объектов. Позиции и размеры используют метрический формат движка; внутри игрового модуля 1 метр соответствует 64 игровым пикселям.
- `scripts/runtime.ts` — `EngineModule`, схемы компонентов, управляемый `RuntimeSession`, интерфейс, ввод, сохранение и корректное освобождение ресурсов.
- `scripts/world.ts` — независимая симуляция с фиксированным шагом 1/120 с, столкновения, прыжки, противники, предметы и финал.
- `scripts/renderer.ts` — собственная Canvas 2D отрисовка сеанса: параллакс, архитектура, персонаж, частицы и освещение. Общий формат сцен, загрузка проекта, валидация, запуск в редакторе, пространства имён сохранений и выпуск Web-сборки принадлежат движку.
- `scripts/audio.ts` — оригинальная процедурная музыка и эффекты Web Audio.
- `scripts/create-scenes.mjs` — воспроизводимый исходник трёх уровней. Повторный запуск заменяет сцены, поэтому не запускайте его после ручных правок без сохранения копии.

Все изображения рисуются программно, звук синтезируется локально. Игра не обращается к внешним серверам, не требует аккаунта, ключей или загрузки сторонних ассетов. Для звука нужен первый клик по кнопке запуска. Поддерживается снижение анимации через системную настройку reduced motion.

## Сборка и проверки

Из корня движка:

```sh
node --experimental-strip-types --test tests/lumen/world.test.ts
npm run build
npm run build:game -- games/lumen
node games/lumen/launch.mjs
```

Сборщик движка создаёт отдельную папку и ZIP в `artifacts/builds/lumen-last-beacon/`. Эту папку можно раздавать любым статическим HTTP-сервером; служба редактора для выпущенной игры не нужна. Самостоятельная сборка не содержит отладочный интерфейс игры. ZIP содержит Web-игру; прямое открытие `index.html` через `file://` не поддерживается ES-модулями браузера.

Набор тестов проверяет родные сцены, физику, двойной прыжок, рывок, здоровье, контрольные точки, сохранения, переходы и финал. Отдельный тест проходит весь маршрут обычными управляющими командами, собирая все девять линз без телепортации и изменения игрового состояния.
