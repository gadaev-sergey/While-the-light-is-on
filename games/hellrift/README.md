# РАЗЛОМ · Последний рубеж

Самостоятельный бесконечный шутер от первого лица на Shelter Engine SDK 1.
Собор пепла, четыре портала, пять типов демонов и один критерий победы: продержаться дольше прошлого раза.

## Играть

- Публичный адрес: https://gadaev-sergey.github.io/hellrift/
- Локально: `node games/hellrift/launch.mjs` (собирает игру при отсутствии сборки).
- Из редактора Shelter Engine: открыть этот проект и запустить пробную игру.

WASD — движение; мышь или ←/→ (также Q/E) — поворот; ЛКМ или пробел — огонь; Shift — рывок с краткой неуязвимостью; 1/2/3 — оружие; Esc/P — пауза; M — звук. Без Pointer Lock можно поворачивать, перетаскивая мышь с зажатой ЛКМ. Прицел по вертикали автоматический. Для телефонов: левый джойстик двигает, правый поворачивает и стреляет.

Пистолет имеет бесконечный боезапас. Дробовик доступен сразу, пулемёт — после 60 секунд. Перезарядка между выстрелами автоматическая. При пустом оружии включается пистолет. Укрытия блокируют выстрелы обеих сторон. Зелёные припасы лечат, янтарные пополняют боезапас, синие дают броню.

Каждые 45 секунд — выбор одного из трёх случайных улучшений. Каждые 90 секунд — новый титан. Частота появления и численность растут; здоровье и урон врагов продолжают увеличиваться без ограничения по времени. Число обычных активных врагов ограничено 78 ради производительности. Лучшее время и число убийств этого забега сохраняются локально; тестовый изолированный сеанс не читает и не пишет прогресс.

## Архитектура

- `scenes/arena.scene.json` — штатная сцена Shelter: расположение опор, укрытий и порталов. Генератор — `scripts/create-scene.mjs`.
- `scripts/world.ts` — детерминируемая симуляция без DOM, столкновения, лучи, AI, прогрессия.
- `scripts/renderer.ts` — Three.js, процедурные материалы и оригинальные модели.
- `scripts/runtime.ts` — управляемый сеанс SDK, ввод, интерфейс, рекорд, пауза и освобождение ресурсов.
- `scripts/audio.ts` — процедурные звуки и ритмическая дорожка Web Audio.

Игра не использует ресурсы, музыку, карты или персонажей DOOM. Графика и звук создаются проектным кодом; внешние шрифты, CDN и сетевые ресурсы не нужны. Требуется WebGL.

## Проверить и выпустить

```sh
node --experimental-strip-types --test tests/hellrift/*.test.ts
npx tsc --noEmit
npm run build:game -- games/hellrift
npm run release:game -- games/hellrift
```
