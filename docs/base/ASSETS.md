# Графика новой базы

Первые пять изображений базы созданы встроенным `image_gen.imagegen`, без CLI или внешнего API. Финальные промпты: [asset-prompts.json](asset-prompts.json). Исходные PNG скопированы в проект без изменения пикселей.

| Путь от корня проекта | Размер / формат | Использование |
| --- | --- | --- |
| public/assets/base/district.png | 1881 × 836, RGB | Дальний жилой квартал, вечернее небо, деревья и ограждения |
| public/assets/base/materials.png | 1536 × 1024, RGB | Шесть фактур: штукатурка, обои, кирпич, доски, бетон, черепица |
| public/assets/base/furniture.png | 1536 × 1024, RGBA | Диван, верстак, кровать, мойка, шкаф, печь |
| public/assets/base/objects.png | 1536 × 1024, RGBA | Генератор, сундук, аптечка, инструменты, электрощит, завал, бочка, ключ |
| public/assets/base/dog.png | 1536 × 1024, RGBA | Шесть поз единственного противника во дворе |
| public/assets/developer-walk.png | 1536 × 1024, RGBA | Сохранённая ходьба разработчика |
| public/assets/developer-attack.png | 1536 × 1024, RGBA | Сохранённая стойка и портрет |
| public/assets/developer-left-punch.png | 1536 × 1024, RGBA | Сохранённый удар левой рукой для отталкивания |

Три новых прозрачных атласа имеют настоящий альфа-канал; полностью или почти прозрачны примерно 54% мебели, 63% предметов и 73% атласа пса. У мебели фактические границы не совпадают с формальной сеткой 3 × 2, поэтому в `renderer.ts` указаны измеренные прямоугольники. Для объектов используются индивидуальные прямоугольники 4 × 2. Внутри прямоугольника рендер измеряет альфа-границы и сохраняет пропорции при размещении на общей опоре.

Сохранённый персонаж уменьшен до масштаба комнат без перерисовки. Кадры привязаны к общему положению стоп, фаза шага — к пройденному расстоянию, а не глобальному времени. Левый кулак используется для короткого отталкивания; прежние суперэффекты и интерфейс боёвки не загружаются.

Новая палитра: холодный серо-синий вечер, угольные тени, приглушённая штукатурка и древесина, мягкий бежевый свет фонаря. Стены, крыша, проёмы, лестницы и торцы дома составлены из новой фактуры по геометрии симуляции. Большие декорации перед персонажем отсутствуют; вдоль двора есть только низкие силуэты травы. Предметы из чужой игры не включены в сборку.

Все старые окружения, монстры, офисные PNG и остальные файлы предыдущего этапа перемещены в `archive/beat-em-up/`. Vite копирует в `dist/` только активный `public/`.

## Модульный повреждённый дом

Добавлен `public/assets/base/house-damage.png` — 1254 × 1254 RGBA, две выбитые оконные рамы, края пролома и небольшие обломки для переднего плана. Около 62% пикселей прозрачны. Атлас создан встроенным `image_gen.imagegen`, скопирован в проект без изменения оригинальных пикселей. [Точный промпт](house-damage-prompt.json), [использование и слои](MODULES.md).

Текущий дом освобождён от мебели и интерактивных предметов. Прежние атласы сохранены для будущего наполнения и предметов двора. Всего загрузчик использует девять PNG; новые маски архитектурных вырезов строятся из альфа-канала в памяти.
