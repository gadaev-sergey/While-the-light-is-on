# Пять вариантов дверей

Концепты для обсуждения, 16 сентября 2026. Не утверждённые изменения GDD и не скриншоты реализации. Код игры не изменён.

Рекомендация: начать с варианта 1. Если двери должны быть заметно шире и выразительнее, рассмотреть вариант 3.

Сейчас `doorGeometry` в `src/base/architecture.ts` выбирает одну соседнюю комнату, отдавая приоритет комнате справа, и использует её перспективу. Это создаёт асимметрию отображения общей двери. Ниже предложены способы изменить эту связь или сам принцип изображения дверей.

## 1. Общий проём для двух комнат

Дверь становится частью общей перегородки. У неё одно состояние и две согласованные проекции — со стороны каждой соседней комнаты. Слева и справа комнаты проёмы строятся зеркально.

Лучший базовый вариант для текущей игры. Сохраняет обычные деревянные двери и неподвижную камеру. Понадобится согласовать отрисовку, положение ручек и перекрытие света с обеих сторон; две проекции не должны выглядеть как две отдельные двери.

## 2. Фронтальная дверная вставка

Дверь на границе комнат показывается почти лицом к игроку, независимо от перспективы стен. При открывании полотно поворачивается ребром, оставляя хорошо читаемый проход.

Самое ясное различие состояний при небольшом масштабе. Потребуется осознанная условность: дверь выглядит более плоской и театральной, чем окружение. Проекция взаимодействия должна совпадать с этой условностью.

## 3. Скошенные дверные ниши

Перед каждым боковым проходом добавляется короткий участок стены под углом около 45°. На этой грани размещается дверь: поэтому широкое полотно видно и слева, и справа.

Наиболее естественный способ сделать двери визуально шире. Потребует новых форм стен, порогов и пола; ниши занимают место. Горизонтальный игровой маршрут нужно визуально совместить с уходящим в нишу порогом.

## 4. Подъёмные двери

В общем боковом проёме устанавливается металлическое полотно, которое уходит вверх в короб над перемычкой. В закрытом состоянии оно заполняет проём, в открытом проход полностью свободен.

Хорошо подходит для бункеров, подвалов и технических помещений. Убирает проблему поворота полотна, но само по себе не исправляет перспективу: общий проём из варианта 1 всё равно нужен. Скважину и привычный жест открывания придётся адаптировать.

## 5. Адаптивный ракурс и разрез

Ракурс немного меняется в зависимости от положения героя. Ближняя часть перегородки, которая заслоняет дверь, плавно скрывается. На иллюстрации она обозначена прозрачным контуром справа.

Сохраняет объём и помогает показать дверь с нужной стороны. Самый сложный вариант для нынешнего Canvas-рендера: меняются проекции окружения и взаимодействий. Скрытие стены для камеры не должно раскрывать герою ещё не видимую комнату. Здесь показан один момент ракурса, не анимация его изменения.
