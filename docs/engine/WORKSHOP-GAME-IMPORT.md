# Перенос игры в Neutral Workshop

По запросу пользователя 29 сентября 2026 года полная игра While the light is on перенесена в уже открытый проект [Neutral Workshop](../../games/neutral-workshop/project.shelter.json). Название, папка и идентичность текущего проекта сохранены. Исходный проект игры не изменён.

Перенесены стартовая сцена «Дом на окраине» с 439 узлами, вся планировка, 28 файлов игрового модуля и 16 файлов графики. Все сцены сравнивались с исходником целиком, код и графика — по SHA-256. В каталоге текущего проекта доступны 21 ресурс: 16 игровых и 5 прежних. Для четырёх GLB указаны измеренные размеры; импортёр принимает встроенные WebP-текстуры, поддерживаемые Three.js.

Игровой модуль включает персонажа и его анимации, взаимодействия с предметами и дверями, лестницы, исследование комнат, пса, инвентарь, генератор, фонарик, освещение, время суток, звук и сохранения. Семь готовых игровых предметов доступны через «＋ Объект / свет / камера». Статические модели из каталога размещаются отдельно от готовых предметов с взаимодействиями.

Перед переносом несохранённые правки открытой нейтральной сцены записаны на диск. Прежние «Главная сцена» и «Галерея» сохранены в самостоятельном проекте [Neutral Workshop — до переноса игры](../../games/neutral-workshop-before-import/project.shelter.json), с отдельной идентичностью. Он добавлен в список недавних проектов. Есть также [точный ZIP до переноса](../../artifacts/engine/workshop-game-import/neutral-workshop-before-import.shelter.zip).

Проверено в Chrome 154.0.8037.58:

- Открытие в редакторе, 439 узлов, 21 ресурс, семь готовых предметов.
- Два цикла «Играть → Пауза → Стоп» без изменения авторской сцены и постоянного прогресса.
- Проход трёх этажей и шести комнат, открытие дверей, получение воды, карта и фонарик.
- Восстановление воды после перезагрузки; сохранение в пространстве текущего проекта.
- Самостоятельный Release-билд, скопированный во временную папку без исходников: корневой и вложенный адрес `/nested/game/`, без обращений к API редактора или внешним ресурсам.
- `npx tsc --noEmit` и 13 проверок `npm run test:engine`.

Артефакты: [отчёт переноса](../../artifacts/engine/workshop-game-import/migration.json), [браузерные проверки](../../artifacts/engine/workshop-game-import/verification.json), [Web ZIP](../../artifacts/builds/95ec5155-c494-49f6-ada3-832c0372ce6b/1.0.0-582925ba.zip), [сцена в редакторе](../../artifacts/engine/workshop-game-import/editor.png).

Последующая проверка 30 сентября подтвердила, что сохранённый проект соответствует проверенному переносу, исходная игра не изменилась, резервная копия и Web ZIP доступны. Текущие правки пользователя в открытом редакторе оставлены нетронутыми.
