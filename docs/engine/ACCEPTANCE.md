# Shelter Engine 0.4 — отчёт приёмки

29 сентября 2026 года. Основа: Three.js 0.186, TypeScript, Vite 7 и локальная служба Node.js. Реализован рабочий путь «проект → сцена → библиотека/импорт → свойства/планировка → пробная игра → сохранение → самостоятельная Web-сборка».

## Результаты

| Проект | Исходный проект | Переносимый проект | Самостоятельная игра |
| --- | --- | --- | --- |
| While the light is on | [games/while-the-light-is-on](../../games/while-the-light-is-on/project.shelter.json) | [Архив проекта A](../../artifacts/engine/releases/2026-09-29/while-the-light-is-on.shelter.zip) | [Web ZIP A](../../artifacts/engine/releases/2026-09-29/while-the-light-is-on-web.zip) |
| Neutral Workshop (нейтральный пример до переноса игры) | [games/neutral-workshop-before-import](../../games/neutral-workshop-before-import/project.shelter.json) | [Архив проекта B](../../artifacts/engine/releases/2026-09-29/neutral-workshop.shelter.zip) | [Web ZIP B](../../artifacts/engine/releases/2026-09-29/neutral-workshop-web.zip) |

После этой приёмки, 29 сентября, по запросу пользователя вся игра While the light is on добавлена в текущий `games/neutral-workshop`: сцена, модуль, 16 файлов графики и каталог ресурсов. Прежний нейтральный проект с последними правками сохранён отдельно по ссылке в таблице; выпущенные ранее ZIP остаются историческими результатами приёмки. Описание текущего проекта: [README](../../games/neutral-workshop/README.md).

Распакованные игры находятся рядом с ZIP в `artifacts/engine/releases/2026-09-29/`. Игра A занимает 30,18 МБ, B — 0,92 МБ до сжатия. У каждой есть `build-report.json` со сценами, модулями и файлами. [Индекс выпуска и SHA-256 архивов](../../artifacts/engine/releases/2026-09-29/release-index.json).

Архив `.shelter.zip` открывается в менеджере редактора. Web ZIP предназначен для статического HTTP-хостинга. Двойной щелчок по `index.html` через `file://` не поддерживается. Публикация в интернете не выполнялась.

## Независимость

Ядро, редактор и общие модули не импортируют `games/while-the-light-is-on` или `src/base`; это проверяется обходом графа импортов. Старые `src/base/*.ts` оставлены совместимыми реэкспортами. Дом, персонаж, игровой UI, эффекты и правила находятся внутри проекта A. Общий Three.js renderer, сцены, ресурсы, команды и SDK используются обоими проектами.

Менеджер проектов открывается без запросов к ресурсам A. Нейтральный проект собран в тестовом окружении без папок игры A, редактора и общей библиотеки. Отдельно копия A открыта и запущена из `/private/tmp/`, вне дерева движка, через тот же публичный SDK.

Проект B создан и настроен действиями интерфейса: библиотечные стол/материал, импорт GLB и текстурированного glTF с подкаталогом, отдельные материалы экземпляров, вращение, свет, камера, две сцены и переход. Созданы три комнаты на двух этажах, дверь, лестница и окно. Вторая сцена работает без планировки и героя. Проект экспортирован, перенесён, заново открыт и собран через интерфейс. Копирование выдаёт новую идентичность, перенос сохраняет её.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm test` | 46 проверок логики, обзора, освещения, сохранений и команд прошли |
| `npm run test:engine` | 12 проверок хранения, архивов, схем, планировки, сборки и зависимостей прошли |
| `npm run test:e2e` | 42 браузерных сценария игры A и редактора прошли |
| `npm run test:engine:e2e` | 5 сквозных сценариев двух проектов прошли |
| `npm run build` | TypeScript и сборка приложения редактора успешны |
| `npm run build:pages` | Игра A собрана с базой `/While-the-light-is-on/` |
| `npm run test:deployment` | Проверены 12 PNG, управление, ручка/скважина двери, фонарик, карта, часы и мобильный экран |
| `node tests/engine/standalone.mjs` | A и B запущены по `/` и `/nested/game/`; все 4 запуска успешны |
| `node tests/engine/lifecycle.mjs` | 10 запусков/остановок без изменения авторской сцены и прогресса; число ресурсов редактора постоянно |

Перед самостоятельной проверкой служба редактора на порту 5174 остановлена. Временный статический сервер раздавал только копии опубликованных файлов; браузер использовал новое хранилище для каждого запуска. Запросы за пределы этого сервера блокировались. Обязательных обращений к API редактора, Vite, исходникам или CDN не было. Отладочные `__BASE__`, `__EDITOR__`, `__RUNTIME__` в готовых играх отсутствуют. Проверены фонарик и карта A, переход в галерею B. [Отчёт самостоятельного запуска](../../artifacts/engine/releases/2026-09-29/standalone-report.json).

В отдельной проверке жизненного цикла после каждой остановки остаётся только главное окно, игровые iframe отсутствуют, авторская сцена и игровые сохранения совпадают с исходными. Счётчики Three.js редактора B после каждого из десяти циклов: 60 геометрий, 7 текстур. [Отчёт циклов](../../artifacts/engine/releases/2026-09-29/lifecycle-report.json). Это ограниченная проверка повторных сеансов, а не длительное профилирование памяти всего браузера.

Отрицательные сценарии: отсутствующий используемый ресурс, несовместимый SDK, ошибка TypeScript, несуществующая сцена/связь, отмена сборки, повреждённый glTF/ZIP, обход каталогов и конфликт внешнего сохранения. Они не дают ложного успешного билда и не заменяют предыдущий результат. Отдельно проверены разница между окном и проходным проломом, геометрическое отверстие лестницы, отмена изменений планировки, независимые материалы и восстановление групп.

## Браузеры, компоновка и производительность

Финальная сквозная проверка выполнена в Google Chrome **154.0.8037.58** на macOS; предыдущий самостоятельный прогон также прошёл в **153.0.8010.53**. Проверены размеры 1440×900, 1280×720 и 347×790, а также игровые сенсорные элементы в эмуляции мобильного экрана 390×844. Основные действия не перекрыты, горизонтального переполнения страницы нет. Safari, Firefox и физические мобильные устройства отдельно не проверялись.

Короткая выборка по 89 межкадровым интервалам редактора при 1440×900: A — 439 узлов, средний интервал 16,67 мс, p95 16,7 мс; B — 7 авторских узлов плюс геометрия планировки, средний интервал 16,67 мс, p95 16,7 мс. Счётчики renderer: A — 634 геометрии/26 текстур; B — 60/7. [Исходные измерения](../../artifacts/engine/releases/2026-09-29/performance.json). Эти значения характеризуют короткий прогон Chrome headless на текущем компьютере и не гарантируют FPS на других устройствах.

Нужны WebGL2 и поддержка ES2022. Сборщик предупреждает о крупном графическом JS-модуле; это не ошибка сборки. Статические GLB/glTF ограничены 64 МБ на файл, 128 МБ на комплект, 500 тысячами треугольников и текстурами до 4096×4096. Скелетная анимация, FBX/OBJ и Draco не входят в реализованный импорт.

Нейтральный шаблон использует простое управление персонажем и комнатную видимость; подробные игровые эффекты, память обзора, дверные позы и поведение пса остаются возможностями модуля A. Новые игровые механики добавляет разработчик через SDK. Нативные сборки, граф программирования и полное воспроизведение возможностей Unreal Engine не заявляются.
